# Nimble DM Helper

A Foundry VTT module for the **Nimble RPG** system. Provides a floating GM window to track player character resources (HP, wounds, mana, class-specific resources) during play.

---

**[Français](#français)** | **[English](#english)**

---

## English

### Features

- **Floating GM Window** - Track all PC resources at a glance without switching between character sheets
- **Real-time Updates** - Auto-refresh when actors, effects, or items change
- **Class Resources** - Displays class-specific resources (Fury, Oaths, Commands, etc.)
- **Quick Adjustments** - Click on resource values to quickly modify them
- **Keyboard Shortcut** - Toggle the window with `Ctrl+Shift+H`
- **Bilingual** - English and French localization

### Supported Classes

Berserker, Mage, Oathsworn, Commander, Hunter, Zephyr, Stormshifter, Songweaver, Shadowmancer, Shepherd, Cheat

### Compatibility

- **Foundry VTT:** v13+
- **System:** Nimble RPG

### Installation

1. In Foundry VTT, go to **Add-on Modules**
2. Click **Install Module**
3. Paste this manifest URL:
   ```
   https://github.com/kenlimero/nimble-dm-helper/releases/latest/download/module.json
   ```
4. Click **Install**
5. Enable the module in your Nimble world

### Usage

- **Toggle Window:** Press `Ctrl+Shift+H` or click the helper button in the token controls toolbar
- **Adjust Resources:** Click on any resource value to modify it
- **Refresh:** Click the refresh button in the window title bar to manually update

## Français

### Fonctionnalités

- **Fenêtre flottante MJ** - Suivez toutes les ressources des PJ d'un coup d'œil sans basculer entre les fiches
- **Mises à jour en temps réel** - Rafraîchissement automatique lors des changements d'acteurs, effets ou objets
- **Ressources de classe** - Affiche les ressources spécifiques à chaque classe (Fureur, Serments, Commandements, etc.)
- **Ajustements rapides** - Cliquez sur les valeurs pour les modifier rapidement
- **Raccourci clavier** - Basculez la fenêtre avec `Ctrl+Shift+H`
- **Bilingue** - Localisation anglaise et française

### Classes supportées

Berserker, Mage, Garde-serment, Commandeur, Chasseur, Zéphyr, Changevent, Tisseur de chants, Ombremancien, Berger, Tricheur

### Compatibilité

- **Foundry VTT :** v13+
- **Système :** Nimble RPG

### Installation

1. Dans Foundry VTT, allez dans **Modules complémentaires**
2. Cliquez sur **Installer un module**
3. Collez cette URL de manifeste :
   ```
   https://github.com/kenlimero/nimble-dm-helper/releases/latest/download/module.json
   ```
4. Cliquez sur **Installer**
5. Activez le module dans votre monde Nimble

### Utilisation

- **Basculer la fenêtre :** Appuyez sur `Ctrl+Shift+H` ou cliquez sur le bouton d'aide dans la barre d'outils des contrôles de jetons
- **Ajuster les ressources :** Cliquez sur n'importe quelle valeur de ressource pour la modifier
- **Rafraîchir :** Cliquez sur le bouton de rafraîchissement dans la barre de titre pour mettre à jour manuellement
